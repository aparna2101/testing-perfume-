# ÉLAN PARFUM — Haute Parfumerie & Signature Scents

A luxury fragrance and haute parfumerie e-commerce web application built with **React**, **Vite**, and modern responsive design.

![ÉLAN PARFUM](https://images.unsplash.com/photo-1592945403244-b3fbafd7f539?auto=format&fit=crop&w=1200&q=80)

## Features

- **Luxury Editorial Aesthetic**: Warm ivory tones, charcoal typography, champagne gold accents, and fluid animations.
- **Hero Campaign Slider**: Multi-slide carousel with auto-play, pause-on-hover, glassmorphism arrow navigation, and numbered slide indicators.
- **Signature Collection Showcase**: 4 flagship perfumes with hover reveals and quick-add functionality.
- **Shop by Mood & Essence**: 6 olfactory families (Fresh, Floral, Woody, Oriental, Gourmand, Citrus).
- **Interactive Scent Finder**: 5 mood profiles with instant real-time perfume recommendations.
- **Comprehensive Shop Catalog**: Multi-attribute filtering (gender, family, concentration, size, price) and real-time note search.
- **Detailed Product Experience**:
  - Interactive hover zoom lens & thumbnail gallery.
  - Scent pyramid (Top Notes, Heart Notes, Base Notes) with longevity & sillage metrics.
  - Bottle volume selectors (30ml, 50ml, 100ml) with dynamic price calculation.
- **Full Shopping Bag (Cart Drawer)**: Real-time subtotal, free delivery progress bar, and quantity adjustments.
- **Wishlist Drawer & Page**: Save favorite scents and move them to bag with one click.
- **Express Demo Checkout**: 2 complimentary deluxe sample selectors, personalized calligraphy gift card, and simulated order confirmation.
- **Live Search Overlay & Account Portal**.

## Tech Stack

- **Framework**: React 19 + Vite
- **Routing**: React Router v7
- **Icons**: Lucide React + custom inline SVGs
- **Styling**: Vanilla CSS with custom luxury tokens and responsive layouts

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/aparna2101/testing-perfume-.git
```

2. Navigate into the folder:
```bash
cd "testing-perfume-"
```

3. Install dependencies:
```bash
npm install
```

4. Start development server:
```bash
npm run dev
```

5. Open [http://localhost:5173](http://localhost:5173) in your browser.
